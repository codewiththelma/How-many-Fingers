# How Many Fingers Game

A guessing game where users try to guess how many fingers are being shown. The game is built with JavaScript and provides instant feedback on the user's guess. It’s a simple yet engaging game that demonstrates the use of JavaScript for user interaction and basic game mechanics.

## Features
- Players try to guess the number of fingers shown.
- Provides instant feedback on the guess.
- Randomly generates a number of fingers from 1 to 5 for each round.
- Simple, engaging, and easy to play.

## Technologies Used
- **HTML**: Structure of the game interface.
- **CSS**: Styling to make the game visually appealing.
- **JavaScript**: Logic for generating random numbers, user input handling, and feedback on guesses.

## How to Play
1. Guess how many fingers are being shown (between 1 and 5).
2. Submit your guess, and the game will immediately tell you if you were right or wrong.
3. Try again to improve your score!
